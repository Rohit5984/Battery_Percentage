# 🔋 BatteryPct

**A lightweight Windows utility for battery monitoring and smart charging alerts.**

BatteryPct displays your battery percentage and reminds you to unplug or recharge at the right time—helping you maintain healthier charging habits without unnecessary features or heavy resource usage.

</div>

---

## ✨ Features

- 🔋 Displays the current battery percentage
- 🔔 **80% battery alert** — popup notification and whistle sound to remind you to unplug the charger
- ⚠️ **25% low-battery alert** — popup notification and whistle sound to remind you to charge your laptop
- 🚀 Optional **Start with Windows** support
- 🖥️ Runs quietly in the background
- 📢 Clean popup notifications with sound alerts
- ⚡ Extremely lightweight, with minimal CPU and memory usage

---

## 🎯 Why BatteryPct?

- 🪶 Lightweight and responsive
- ⚡ Minimal CPU and memory usage
- 💻 Designed to run in the background without slowing down your PC
- 🔋 Encourages better charging habits through timely notifications
- 🎯 Focused on one job: monitoring your battery and notifying you when it matters

---

## 🔔 Battery Alerts

| Battery Level | Alert |
| ------------- | ----- |
| **80%** | Popup notification + whistle sound — *Unplug your charger* |
| **25%** | Popup notification + whistle sound — *Charge your laptop* |

## 🛠️ Installation

1. Download the latest release.
2. Extract the files if required.
3. Run `BatteryPct.exe`.
4. Optionally enable **Start with Windows**.
5. Keep BatteryPct running in the background to receive battery notifications.
